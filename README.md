# BiliLens

> 为 B 站视频提供 AI 辅助的摘要生成功能：自动获取字幕，并通过兼容 OpenAI 接口的模型流式输出视频总结。

BiliLens 是一个 Tampermonkey 用户脚本，运行于 B 站视频页面。它能够在不离开当前页面的前提下，获取 AI 生成的内容摘要。脚本通过拦截页面字幕请求获得字幕文本，调用用户配置的大语言模型接口，以流式方式渲染总结结果，无需额外安装浏览器插件或手动复制字幕。

## 功能概述

在任意 B 站视频页面，脚本会在视频播放器下方右侧工具栏插入一个“AI 总结”按钮，样式与原生工具栏按钮保持一致。点击该按钮后，脚本自动完成以下流程：模拟用户交互触发字幕加载，拦截并解析 AI 字幕数据；将字幕文本与预设提示词组合后发送至用户指定的 API；接收流式响应并逐 token 渲染为 Markdown 格式的总结，显示在毛玻璃悬浮面板中。整个过程无需用户干预，等待数秒即可查看结果。

## 功能列表

### 已实现

- [x] **自动获取 AI 字幕**：通过模拟用户操作触发页面加载字幕资源，拦截响应数据后自动恢复字幕按钮状态，避免干扰正常观看。
- [x] **流式 AI 总结**：基于 SSE 逐 token 渲染，实时显示模型输出，支持任意兼容 OpenAI Chat Completions 格式的 API（如 DeepSeek、通义千问、GPT-4o 等）。
- [x] **轻量级 Markdown 渲染器**：使用原生 JavaScript 实现，支持标题、列表、引用、代码块、加粗、斜体等常见语法，不引入任何外部依赖。
- [x] **总结导出**：支持将总结复制导出，便于分享至笔记或社交平台。
- [x] **融入 B 站原生工具栏**：入口按钮复用 B 站工具栏的 CSS 类名，与点赞、投币、收藏等原生按钮排列一致。
- [x] **毛玻璃悬浮面板**：使用 `backdrop-filter` 实现毛玻璃效果，配合弹性动画，减少对观看体验的干扰。
- [x] **SPA 路由适配**：监听 `pushState`、`replaceState` 及 `popstate` 事件，在视频切换时自动重置脚本状态并重新注入入口按钮。
- [x] **API 密钥本地存储**：密钥通过 Tampermonkey 提供的 `GM_setValue` 接口保存在浏览器本地，不写入页面 DOM、不输出至控制台、不发送至第三方。
- [x] **流式失败自动降级**：当 SSE 流式响应无内容或超时时，自动回退为普通 JSON 请求，并设置 3 分钟超时保护。
- [x] **复制 Markdown 原文**：总结完成后提供复制按钮，可一键复制原始 Markdown 文本。
- [x] **自定义提示词**：内置默认提示词，允许用户修改为任意总结风格。
- [x] **Toast 轻提示**：操作结果通过页面顶部短暂出现的 Toast 消息反馈，不打断阅读。

## 隐私与安全

本脚本涉及 API 密钥的存储与使用，相关安全说明如下：

- **密钥存储位置**：通过 Tampermonkey 的 `GM_setValue` API 保存在浏览器本地存储中，与当前浏览器及设备绑定，更换环境需重新配置。
- **密钥使用范围**：仅在向用户自行配置的 API 地址发起请求时作为请求头或参数发送；不会写入页面 DOM、不会输出到控制台日志、不会上传至任何未指定的服务器。
- **字幕数据传输**：字幕文本从 B 站页面内拦截获取后，与预设提示词拼接，通过 `fetch` 发送至用户配置的 API 地址，传输路径不经过第三方服务。
- **代码可审计性**：脚本为单个 `.user.js` 文件，无构建步骤、无外部依赖，所有逻辑均可直接检查。

## 安装

1. 安装浏览器扩展 Tampermonkey（支持 Chrome、Edge、Firefox）。
2. 在 Tampermonkey 中新建脚本，将 `bili-lens.user.js` 文件内容粘贴后保存。
3. 打开任意 B 站视频页面，右侧工具栏中会出现“AI 总结”按钮。
4. 首次使用点击该按钮，在设置弹窗中填写 API URL、API Key 与模型名称，保存。
5. 再次点击“AI 总结”按钮，开始生成总结。

### API 配置参考

| 服务商 | API URL | 模型名示例 |
|--------|---------|------------|
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1/chat/completions` | `gpt-4o` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-plus` |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `deepseek-ai/DeepSeek-V3` |

任何兼容 OpenAI Chat Completions 格式的 API 均可使用。

## 技术架构

```
B 站视频页面
    │
    ├─ Hook fetch & XHR ──→ 拦截 aisubtitle.hdslb.com 字幕请求
    │                         获取 JSON 后自动关闭字幕显示
    │
    ├─ 模拟用户操作 ──────→ 点击字幕按钮 → 选择 AI 中文字幕
    │                         触发页面加载字幕文件
    │
    ├─ AI 总结 ───────────→ 字幕文本 + 用户提示词 → OpenAI 格式 API
    │                         SSE 流式接收 → 节流 Markdown 渲染
    │                         失败时回退为普通 JSON 请求
    │
    ├─ UI ───────────────→ 入口按钮复用 B 站原生工具栏样式
    │                         毛玻璃悬浮面板（backdrop-filter）
    │                         自带 Markdown 渲染器（无外部依赖）
    │
    └─ SPA 路由 ─────────→ Hook pushState / replaceState / popstate
                              切换视频时自动重置状态、重新注入按钮
```

脚本完全自包含，不引入任何外部 JS 库，Markdown 渲染器由原生代码实现，所有逻辑集中在一个文件中。
